Personal Google Tools

This is a private tool. I use it to read and organize my own Google account from the command line: Gmail, Calendar, Drive, Docs, Sheets, and Contacts. It runs on my own computers.

Who can use it

Only me. It is not a product. There is no sign-up, and it is not offered to anyone else.

Google sign-in

When I connect the tool to my Google account, the Google sign-in screen shows the app name "Craft Agent". This page and the privacy policy describe that app.
