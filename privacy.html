Privacy Policy

Last updated: November 6, 2026

This policy covers the private tool described on the home page. The Google sign-in screen shows it as "Craft Agent".

Who uses the tool

One person, the owner. The tool connects only to the owner's own Google account. No other person can sign in.

What data the tool reads

With the owner's permission, the tool can read and change data in the owner's own Google account: Gmail messages, drafts, and labels, Calendar events, Docs, Sheets, and Contacts. It can read files in Google Drive but cannot change them.

How the data is used

The tool uses the data to search, read, organize, and draft items for the owner. The owner may process this data with software and services that the owner chooses, such as an AI assistant, for the owner's own use.

The data is not sold. It is not used for advertising. It is not shared with other parties for their own purposes.

Where the data is kept

The sign-in token is kept in the system keychain on the owner's own computers. Files that the tool downloads are kept on those computers. The tool has no server and no database of its own.

Data from other people

The tool does not collect data from visitors or from any other person. This website has no forms, no cookies of its own, and no analytics. GitHub hosts the site and may keep its own visit logs.

How to remove access

The owner can remove the tool's access at any time on the Google Account permissions page: myaccount.google.com/permissions.

Contact

Open an issue on this site's GitHub repository.
